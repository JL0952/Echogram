# EchoText Custom

A personal fork of [SillyTavern-EchoText](https://github.com/mattjaybe/SillyTavern-EchoText) by mattjaybe.

## Modifications

- Modified EchoText's prompting logic.
- Added support for reading the character's `first_mes` and recent SillyTavern story context and a character limit for story context.
- Added WeChat interface, money transfers, multi-bubble replies, photo messages, consecutive sending, and verbosity-based text counts.
- Added character avatar and WeChat font customization.
- Added voice messages, tapback reactions, and file and link sharing.
- Added an emotion and personality popup: Rapport, Romance, Desire and moods, Big Five traits, Morality, locks and a texting style, which shape how the character texts.
- Proactive messages can include photos and voice messages.
